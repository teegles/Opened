This is Fold Count's first optimized, permanently signed beta release.

Important: earlier GitHub APKs were development-signed. If one is installed,
uninstall it before installing this version. That one-time transition removes
the existing local statistics. Releases after this one will install as normal
updates.

Highlights:

- Today, 7 Days, and All Time statistics
- Opened/closed screen-on time and daily history
- Material You interface with system light/dark mode
- No internet, location, or app-usage permission
- Persistence and accessibility improvements
- Optimized APK reduced from about 29 MB to 1.8 MB
