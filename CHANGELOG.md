# Changelog

## 0.3.0-beta

- Added Today, 7 Days, and All Time views.
- Added per-day opened and closed screen-on history.
- Refreshed the interface with Material You styling and system light/dark mode.
- Added a custom Fold Count icon and clearer opened/closed terminology.
- Removed app-usage access and all related permission prompts.
- Improved tracking persistence, accessibility, notifications, and privacy.
- Reduced the distributable APK from a 29 MB debug build to an optimized,
  permanently signed release build of roughly 2 MB.
